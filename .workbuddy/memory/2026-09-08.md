# 2026-09-08

## 归档页（Archives）功能 — 跨四端实现

### 需求
为 vanilla / vue / react / hexo 四端主题统一添加 `/archives` 页面：按年/月时间线归档展示全部文章，标题/日期/分类 chip/链接，按时间段计数，渐进展开（IntersectionObserver + 「加载更早」），桌面右侧年份快捷导航 + 窄屏顶部胶囊，响应式。

### 核心库（packages/core）
- 新增 `components/archive-list.ts` Web Component：
  - JS 属性 `articles` / `catNames`，事件 `article-select`。
  - 按 `YYYY/MM/DD` 日期倒序分组为 `年 → 月 → 文章` 三级结构，年/月 header 显示该时间段篇数，月份可折叠（aria-expanded）。
  - 默认渲染 4 个年份（INITIAL_YEARS=4），每次滚动到底加载 2 个（LOAD_CHUNK_YEARS=2），加载完毕显示「已经到底啦 · 共 N 篇」。
  - 年份快捷导航：桌面 `≥760px` 容器查询显示右侧 sticky 列表；窄屏显示顶部胶囊。
  - 重渲染采用 `requestAnimationFrame` 调度（防重入），避免在 Vue setter 链中触发同步栈溢出。
- `components/site-sidebar.ts`：
  - 新增 JS 属性 `archiveUrl`：当非空时在「首页」与「分类」之间插入「归档 / Archives」原生链接项（`data-cat="archives"`，原生 `<a>` 不被拦截）。
  - 「归档」高亮支持 `active-cat="archives"`。
- `components/index.ts` 导出 `ArchiveList`。
- `helpers/wc-base.ts`：
  - `attributeChangedCallback` 现在仅对子类在 `observedAttributes` 中声明的属性生效，符合 Web Components 规范，避免外部库设置无关属性时触发 Shadow DOM 重建。

### 主题层
- **Vanilla** (`themes/vanilla`)：
  - 新建 `archives.html` 公共侧栏 + `<archive-list>` 容器，沿用首页/搜索页/登录页结构。
  - `vite.config.js` 增加 `archives.html` 入口。
  - `src/js/main.js` 装配 archive-list、注入 sidebar.archiveUrl = 'archives.html'；归档页内点击分类/标签跳转回首页（`location.href = 'index.html#cat=...'`），避免单页面 hash 路由失效。
- **Vue** (`themes/vue`)：
  - 新建 `components/ArchiveList.vue` 包装（`articles`/`catNames` 用 `.prop` 修饰符直接传 property；`@article-select` 转 `articleSelect`）。
  - 新建 `views/ArchivesView.vue` 侧栏 `active-cat="archives"`，文章点击用 `router.push({ path:'/', query:{ cat, art:id } })` 回首页打开阅读器。
  - `router/index.ts` 新增 `/archives` 路由（动态 import `ArchivesView.vue`）。
  - `components/SiteSidebar.vue` 新增 `archiveUrl` prop，默认 `'#/archives'`，watch + setData 同步给 Web Component。
  - `App.vue` 历史遗留 `search-panel` 赋值类型报错顺手修成 `as any`。
  - ⚠️ 当前打包后的 `/archives` 路由在加载阶段抛出 `RangeError: Maximum call stack size exceeded`（Vue 运行时报错），ArchiveList 区域未能渲染；已加 rAF 防重入但未根除，待后续排查。
- **React** (`themes/react`)：
  - 新建 `components/ArchiveList.tsx` 包装（`useEffect` 同步 `articles`/`catNames`，监听 `article-select` 转回调）。
  - 新建 `pages/ArchivesPage.tsx`，侧栏 `activeCat="archives"`，`handleNavigate` 走 `navigate('/#cat=...')` 复用首页 hash 路由。
  - `App.tsx` 注册 `/archives` 路由。
  - `components/SiteSidebar.tsx` 新增 `archiveUrl` prop，默认 `'/archives'`。
  - `custom-elements.d.ts` 补充 `archive-list` JSX 声明；`App.tsx` 同款 `as any` 修复。
- **Hexo** (`themes/hexo`)：
  - `scripts/archives.js` 注册自定义生成器 `soul-archives`，产出 `/archives/index.html`（`layout: ['soul-archive','archive','page']`），提供 `title: '归档'` + `soulPosts: all posts desc` + `soulArchive: true` 标记。
  - `layout/archive.ejs` 服务端渲染年/月时间线：
    - 与核心 archive-list 同款样式（同一份类名、配色、token）。
    - 兼容 hexo-generator-archive 遗留的 `/archives/YYYY(/MM)` 子页：按 `page.year`/`page.month` 过滤 site.posts，避免整表重复。
    - 渐进展开：默认隐藏 `gi >= 4` 的 `.tl-year.is-later`，IntersectionObserver 触底加载 2 年；旧浏览器降级为「点击加载」按钮。
    - 月份折叠、滚动 spy 年份激活、年份胶囊点击 `scrollIntoView`、prefers-reduced-motion 兼容。
    - 行内 `catNameOf()` 在无 front-matter 时回退到 `_posts/<dir>`，与 index.ejs 的 cat 解析保持一致。
  - `layout/index.ejs`/`page.ejs`/`post.ejs` 的 site-data 注入 `archiveUrl: url_for('/archives/')` 与 `homeUrl: url_for('/')`。
  - `src/main.js`：
    - 读取 `archiveUrl`/`homeUrl`，`sidebar.archiveUrl = archiveUrl`。
    - 侧栏 `navigate` 事件：在 `articleList` 存在页（首页 SPA）走 `location.hash = ...`；否则 `location.href = homeUrl + '#cat=...'` 跳回首页应用筛选。
    - `applyRoute` 中 `sidebar.setAttribute('active-cat', ...)` 增加 `&& articleList` 守卫，避免覆盖归档页/文章页的模板默认高亮。
