## 本地多栈 dev server 端口分配（WSL 内运行）

在 WSL 里把各主题 dev server 全部拉起，Windows 侧通过 localhost 访问（WSL2 localhostForwarding 生效）。

| 服务 | 端口 | 启动命令（在 WSL 内） |
| --- | --- | --- |
| hexo 测试站 | 4000 | `cd /tmp/hexo-test && hexo server -p 4000`（已常驻） |
| vanilla | 5173 | `themes/vanilla` → `vite --port 5173 --strictPort --host 127.0.0.1`（已常驻） |
| vue | 5175 | `cd themes/vue && pnpm dev --host 0.0.0.0 --port 5175 --strictPort` |
| react | 5176 | `cd themes/react && pnpm dev --host 0.0.0.0 --port 5176 --strictPort` |

注意点：
- 5174 被别的仓库 `~/code/dropspot-workplace`（electron-vite dev）占用，不要占用。
- 从 Windows 侧启动 WSL 内常驻服务用：`wsl.exe -e bash -lc 'cd <dir> && setsid nohup <cmd> > /tmp/x.log 2>&1 < /dev/null &'`，进程不会随 wsl.exe 退出被杀。
- React 启动会有 `esbuild` / `optimizeDeps.esbuildOptions` 废弃警告（vite 8 已改用 rolldown/oxc），不影响运行。
