## vue 阅读器内点击 tag 白屏修复（共享组件 + vue-router 接管）
- 现象：vue(5174) 首页打开文章阅读器，点正文 tag → 整页空白（HomeView 卸载）。
- 根因：`article-viewer`(packages/core) 把 tag 跳转**写死** `location.hash = '#tag=xxx'`——对 hexo/vanilla/react 的纯 hash 路由有效；vue 用 vue-router `createWebHashHistory`（hash 内 query 结构 `#/?cat=&art=`），hash 被改写成非法路径 `#/tag=xxx` → 无匹配路由白屏。
- 修复：
  1. `wc-base.emit` 增加 `{ cancelable }` 选项并返回 CustomEvent（向后兼容）；
  2. `article-viewer` tag 点击先派发 **cancelable 'tag-select'**：宿主 preventDefault 即接管（不关阅读器、不写 hash），未接管保持旧行为——hash 型端零回归；
  3. vue 端：ArticleViewer.vue 转发 tag-select 并 preventDefault；HomeView @tag-select → `router.push({query:{tag}})`（阅读器随 art 移除由 watcher 自动关闭）；`onViewerClose` 改为仅当 URL 仍带 art（用户点 ×/Esc/遮罩）才回落 `{cat}`，避免外部导航关闭时路由被再次改写；
  4. App.vue 补齐按路由维护 title，watch route.query.art 为 null（关闭/点 tag）时还原标题（消除残留文章标题）。
- CDP 实测：点 tag → `#/?tag=duxcms`、阅读器关、列表过滤 8 篇（duxcms mock 恰好 8）、active-tag、标题还原「CallMeSoul - 首页」；react(5175)/vanilla(5173) hash 回归通过（仍 `#tag=duxcms`）。
- commit：`bf9a5c2`(core)、`fb4c68c`(vue)。注意 vue App.vue 夹带了先前未提交的 applyRouteTitle(4.2 title)基线，message 已注明。
- 经验：wc 组件内不要写死宿主路由方式；框架路由型宿主(view-router)应通过可取消事件接管，hash 型宿主保持组件默认。

## react 阅读器内点击 tag：弹窗不关闭/标题残留（同 vue 修复思路补 react）
- 现象：react(5175) 打开详情弹窗点正文 tag → URL/列表已变 `#tag=duxcms`（过滤 8 篇、active-tag 就位），但**弹窗一直开着**、标题残留文章名。与 vue 白屏同源不同表现。
- 根因：vue 修复时给 core 加了可取消 `tag-select`，但 **react wrapper(ArticleViewer.tsx) 未监听/preventDefault**，点击走 fallback（emit viewer-close → 50ms 后写 `#tag=`）。而 react HomePage `onViewerClose` 无条件 `isClosingByUser.current=true` + 回落 `#cat=` → currentArtId 变 null 后，effect 的自动关闭分支 `!isClosingByUser` 被守卫拦截 → 弹窗永远不关；且 react 全端从未还原关闭后的 document.title（vue 在 App.vue watcher 还原、vanilla/hexo 在 applyRoute/内联脚本还原）。
- 修复（仅 react 两个文件，commit `2f9cb8b`）：
  1. `ArticleViewer.tsx`：新增 `onTagSelect` prop，effect 里监听 `tag-select` 并 `preventDefault()` + 转发 tag（同 vue wrapper onWcTagSelect）；
  2. `HomePage.tsx`：viewer 传 `onTagSelect={handleTagSelect}`（复用列表 tag 的 `#tag=` 导航）；`handleViewerClose` 加守卫 `if (getHashArt())` 才回落 `#cat=`（避免外部导航/切 tag 引发的 viewer-close 二次改写 hash），关闭后统一 `document.title = siteName + ' - 首页'`。
- CDP 实测：点 tag → 弹窗关、URL `#tag=duxcms`、过滤 8、标题还原；点 × → `#cat=all` 正常回落；弹窗开着外部导航 `#cat=duxcms` → 弹窗自动关且 hash 不被覆盖（旧代码会因守卫无条件写回 currentCat 覆盖新导航）；过滤后重开文章正常。`tsc -b` 通过。
- 教训：core 补可取消事件时，要同步检查**所有宿主 wrapper** 是否已接管（vue 改了 react 漏了）；react 端此前无任何关闭标题还原逻辑，属既有欠账，本次顺手补齐。
