## 需求概述
修复博客阅读器打开文章详情时，封面在放大动画过程中被非等比拉伸/压扁（几乎所有文章都出现），动画结束后恢复正常的问题。

## 根因
卡片缩略图 `.card-thumb` 的裁切窗口恒为 `430:190`（源图中心横幅），而详情封面 `.viewer-cover` 是「宽度通栏 + `max-height:400px` 夹取」，实际显示窗口比例随正文列宽与源图比例浮动（常见约 1.5~3.5:1）。打开动画在两种不同比例的窗口间做 FLIP 非等比 `scaleX/scaleY` 插值，导致过程必然变形；动画结束克隆移除、露出真实封面后才恢复。

## 已确认取舍
用户接受将详情封面固定为与卡片相同的 `430:190` 横幅中心裁切（object-fit:cover、object-position:center），以彻底消除变形并实现开合像素级无缝。

## 目标效果
- 打开动画全程封面严格等比缩放、零拉伸；
- 打开结束、关闭落回卡片均无缝衔接（与既有「关闭后再打开闪烁」修复协同）；
- 详情封面视觉仍为深色玻璃拟物风的通栏头图横幅，无其余布局改动。


## 技术栈
- 纯 CSS 规则调整，位于 `vite/src/css/style.css`，经现有 Vite 构建；不引入新依赖、不新增文件、不改动 `vite/src/js/main.js`。
- JS 侧打开（约 739-792 行）与关闭（约 900-942 行）动画均通过 `getBoundingClientRect()` 动态实测缩略图与封面矩形，不硬编码宽高/比例，因此只需修改 CSS 盒规则即可自动对齐，无需动 JS。

## 实现方案
### 关键决策
1. **用 `aspect-ratio: 430 / 190` 取代 `max-height: 400px`**（`.viewer-cover`，style.css 1537-1546 行），与 `.card-thumb`（218-229 行）的裁切窗口同构：两端窗口比例一致，且同为源图中心裁切 → FLIP 全程等比、末帧像素级一致。
2. **二者不可并存**：若保留 `max-height`，超宽时会把盒高夹成非 430:190，窗口比例重新漂移、变形复现，因此必须移除。
3. **超大屏封顶**：`.viewer-main` 无 `max-width`（正文段落自身才 794px），纯 `aspect-ratio` 在 4K 全屏下封面高度可达 900px+，超出原 400px 上限的观感。故增加 `max-width: 905px`（905 × 190/430 = 400px，恰为旧版高度上限对应宽度）：中等及以下窗口宽度不受影响（`width:100%` 生效），仅超宽屏收住，且 `max-width` 只限宽、高度由比例派生，盒比例恒为 430:190，不破坏对齐。保持块级流布局与 `margin: 26px 0 30px` 不变，不做居中处理，避免与正文区左对齐产生观感错位。
4. **小屏适配自动成立**：≤1280/900/700 断点下正文列变窄，封面宽按 100% 等比收缩，高度自然受限，无异常撑高。

### 最终样式
```css
.viewer-cover {
  display: block;
  width: 100%;
  max-width: 905px;            /* 超宽屏按 430:190 等比收住，高度上限≈原 400px */
  aspect-ratio: 430 / 190;     /* 与 .card-thumb 同一裁切窗口：开合 FLIP 全程等比无拉伸 */
  object-fit: cover;
  object-position: center;
  border-radius: 2px;
  background: #252828;
  margin: 26px 0 30px;
}
```
其余属性（display/object-fit/object-position/border-radius/background/margin）均保持现状。

## 执行细节与回归控制
- 仅修改 `vite/src/css/style.css` 的 `.viewer-cover` 规则，不触碰 `main.js` 及其它选择器，最小化爆炸半径。
- 不需新增日志/性能处理：纯样式声明，无运行期开销，不影响 backdrop-filter、reveal 淡入时序（coverLocal 由 rectOf 实测，自动适配新盒高）。
- 验证要点：
  1. 多分辨率（约 1280/1440/1920 及 >1920 超宽）打开任意多篇文章：动画全程封面无拉长/压扁；
  2. 打开结束瞬间与关闭收拢落回卡片时无跳变；同目录开即关不闪烁（既有修复不回归）；
  3. 封面裁切构图与卡片缩略图一致（同一中心横幅）；
  4. ≤900/700px 单栏小屏下封面比例正常、页面无异常撑高；
  5. 详情封面常规观感（横幅通栏、圆角、边距）保持不变。
